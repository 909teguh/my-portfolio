Setahun terakhir saya benar-benar produktif dalam hal coding. tahun lalu saya mulai menggunakan windsurf kemudian seiring waktu saya menemukan tools, agent, dan ide lain yang memanfaatkan AI sampai sekarang setup saya adalah google Antigravity + open code. Mungkin setelah ini saya akan coba juga menggunakan openrouter dan timbang mana yang lebih hemat. Soal model, saya lihat deepseek cukup bagus untuk pekerjaan sehari-hari. jika butuh model yang lebih pintar, bisa gunakan claude gratis bawaan antigravity. So yeah, sejauh ini semua sangat mulus dan mampu menstimulus saya agar bersemangat coding.

## Flashback Pandangan Saya tentang Coding

Waktu masih kuliah dulu, saya sempat stress karena sebegitu bingungnya dengan dunia IT. Saya merasa salah jurusan karena memang dari kecil jiwa saya adalah seni, sementar IT adalah dunia yang terlalu rumit menurut saya waktu itu. Saya sampai ikut ujian SNMPTN dua kali karena ingin pindah jurusan. Walaupun waktu itu akhirnya lulus di jurusan lain yang lumayan OK, akhirnya saya memutuskan untuk tetap di UI dengan alasan yang membingunkan juga kalau diingat-ingat sekarang. Sampai waktu mendapatkan kerjaan pertama di Jakarta-pun, saya masih cukup clueless soal programming. Tapi siapa sangka saya jatuh cinta ke dunia programming justru setelah menjadi CPNS.\
Menjadi PNS, terutama PNS Pemda seperti yang saya jalani saat ini adalah pekerjaan yang secara beban bisa dibilang santai. Tidak ada tekanan yang berat seperti di swasta. Saya merasa itu memberi dampak positif sehingga saya bisa belajar dengan pace yang saya inginkan. selain itu, kebetulan Pemda tempat saya bekerja bisa dibilang cukup suportif terhadap inovasi dan selalu mendorong pemanfaatan IT.

Saya ingat tugas yang melibatkan programming yang pertama saya lakukan adalah untuk bidang saya terkait pendataan tenaga honorer. Aplikasi itu saya buat menggunakan Laravel dan saat ini hasilnya sangat jelek. aplikasi itu tidak mengikuti kaidah standar sebuah aplikasi. Saya belum menerapkan role and permission disitu. Datanya bisa di akses semua user, jadi memang sangat bikin malu kalau diingat. tetapi aplikasi sejelek itu saja mendapat apresiasi waktu itu, dan lumayan berdampak. sejak saat itu datang beberapa tawaran dari beberapa pihak untuk meminta saya membuatkan aplikasi dan itu lumayan mendatangkan tambahan uang.

sejak 2019 saya mulai berangsur fokus membangun aplikasi untuk kebutuhan saya sendiri di kantor. Saya menanamkan mindset bagaimana agar kerjaan dikantor menjadi lebih ringan berkat teknologi karena kebetulan salah satu kerjaan saaya melibatkan proses repetitif yang membosankan. Kemudian juga sering ada kegiatan yang membutuhkan koordinasi dengan OPD yang saya pelajari sangat sulit untuk mendapatkan data dengan kualitas yang bagus. Masalah pengumpulan data ini faktanya masih menjadi masalah bagi saya sampai saat ini. Saya belum menemukan solusi efektifnya.

## Vibe Coding Sang Akselesator

Sejak coba-coba vibe coding tahun lalu, dunia terasa sangat berubah. saya tidak perlu lagi menelusuri stackoverflow, cukup tanya AI. Selain itu AI juga bisa menuliskan codenya untuk kita, cukup buatkan promptnya saja. Selain itu, seiring waktu, saya juga mulai terlatih membuat prompt yang lebih efektif serta mampu membuat plan yang lebih bagus sehingga bisa hemat token, minim bug, dan sesuai dengan yang diharapkan.

AI membuat saya percaya diri.

> Sekarang rasanya tidak ada lagi yang tidak mungkin, selalu ada AI tempat bertanya, selalu ada AI untuk menemukan solusi yang lebih baik

Perjalanan kedepan masih panjang, model-model semakin cerdas, coding akan semakin mudah. Ada banyak ide yang ingin saya tuangkan tanpa perlu khawatir apakah saya mampu secara teknis mengerjakannya, karena ada AI tempat bertanya.
