**Inkarn8: The Cursed Codex: Steam Capsule Art**

I created the Steam capsule illustrations for *Inkarn8: The Cursed Codex*, a dark fantasy roguelite from YNG8 Studios. The game takes place inside a cursed spellbook: every page is a room, every chapter is a floor, and players draw sigils to cast spells.

Since the game is about magic and corruption, the style here was realistic and dark, a big shift from my earlier capsule work. I built the capsule designs to carry that mood, so the game’s atmosphere comes across before anyone even reads the description.

![](/images/work/inkarn8/inkarn8vertical.JPG)

I also refined the game’s logo so it would better match the world of the game and sit naturally within the capsule art.

You can learn more about the game at [inkarn8game.com](https://www.inkarn8game.com/).
